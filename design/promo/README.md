# Материалы для рекламного поста

| Файл | Что это |
|---|---|
| `promo-1080.png` | обложка поста, 1080×1080 |
| `_promo-main.html` | исходник обложки |
| `post-text.md` | три варианта текста поста |

Обложка пересобирается из корня репозитория:

```
python3 /путь/к/shot-crop.py "file://$PWD/design/promo/_promo-main.html" design/promo/promo-1080.png 1080 1080
```

Скриншот внутри обложки берётся из `design/store/screen-1-search.png` —
обновите его, если интерфейс изменится, иначе реклама будет показывать
старую версию приложения.

> Скриншоты сняты на выдуманных данных. Для карточки приложения это
> приемлемо, а в рекламном посте выдуманные имена и отзывы — уже обещание,
> которого никто не давал. Когда появятся настоящие поездки, пересними.
