# Промо-ролик

| Файл | Что это |
| --- | --- |
| `po-puti-promo-1080.mp4` | 1080×1080, 12,6 с — основной, для ленты ВКонтакте и Telegram |
| `po-puti-promo-stories.mp4` | 1080×1920 — та же анимация с полями, для сторис |
| `po-puti-promo-640.gif` | 640×640, 16 кадров в секунду — там, где видео не запускается само |
| `_promo-video.html` | Исходник анимации |

## Как он собран

Анимация не записана с экрана, а посчитана покадрово. Вся раскадровка — одна
функция `render(t)`: по времени в секундах она расставляет прозрачности и
смещения, а CSS-переходов и таймеров в странице нет вовсе. Любой кадр
достаётся по адресу `_promo-video.html?t=8.5`.

Так сделано не ради красоты: при записи реального воспроизведения кадры
ложатся с неровным шагом, и на склейке это видно как подрагивание. Здесь
кадр детерминирован — перерисовка через неделю даст тот же результат.

Сборка:

```bash
# кадры: 315 штук, 25 кадров в секунду
seq 0 314 | xargs -P 8 -I{} sh -c 'T=$(awk "BEGIN{printf \"%.4f\", {}/25}");
  chromium --headless --screenshot=frames/f$(printf %04d {}).png \
  --window-size=1080,1080 "file://$PWD/_promo-video.html?t=$T"'

ffmpeg -framerate 25 -i frames/f%04d.png -c:v libx264 -preset slow -crf 20 \
  -pix_fmt yuv420p -movflags +faststart po-puti-promo-1080.mp4

ffmpeg -framerate 25 -i frames/f%04d.png \
  -vf "fps=16,scale=640:-1:flags=lanczos,split[a][b];[a]palettegen=max_colors=192[p];[b][p]paletteuse=dither=bayer:bayer_scale=3" \
  po-puti-promo-640.gif
```

`yuv420p` обязателен: без него часть плееров и соцсетей покажет чёрный кадр.
Для GIF нужна своя палитра — со стандартной мягкие тени рассыпаются в полосы.

## Что внутри

| Время | Сцена |
| --- | --- |
| 0–3 с | Маршрут рисует себя: Оренбург, промежуточная точка Соль-Илецк, метка Акбулак |
| 3,5–7 с | Телефон с экраном поиска, подпись «Видно, кто уже едет» |
| 7–10 с | Карточка поездки, подпись «Цена, места и кто за рулём» |
| 10,3–12,6 с | Иконка, название, города и кнопки площадок — по очереди |

Экраны в телефоне — настоящие снимки приложения из `design/store/`, страница
ссылается на них напрямую, копий рядом нет: разъехались бы при первой же
пересъёмке скриншотов.

Промежуточная точка нарисована меньше конечных, подпись к ней мельче и
серая — по размеру видно, что это остановка по пути, а не пункт назначения.

## Чего в нём нет

**Звука.** В ленте видео обычно играет без него, для сторис музыка пригодилась
бы — но подбор трека это вопрос прав, а не монтажа.

**3D.** Ролик, с которого брали пример, собран из трёхмерных моделей с
движением камеры. Здесь этого нет и не будет: имитация объёма средствами CSS
читается как подделка. Вместо неё в кадре настоящий интерфейс — для сервиса,
который уже работает, это сильный аргумент, а не слабый.
