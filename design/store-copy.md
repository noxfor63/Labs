Готово к копированию. Ограничения полей взяты из кабинета разработчика по
снимкам экрана, а не по памяти.

статичная маленькая.

## Название

Название приложения — «По пути». Само по себе оно не объясняет, о чём
приложение, а в каталоге название — главный способ это сделать. Лимит 34
символа позволяет добавить пояснение:

```
По пути — попутчики Оренбуржья
```

30 символов. Если хотите оставить чистое название:

```
По пути
```

Во втором случае особенно важно краткое описание ниже: без него человек
в каталоге не поймёт, что это за приложение.

## Краткое описание

До 128 символов. Этот вариант — 111 символов:

```
Попутчики между Оренбургом и райцентрами: Соль-Илецк, Акбулак, Илек, Александровка. Поиск по дню, цене и местам
```

Если захочется короче (51 символ):

```
Попутчики между Оренбургом и райцентрами Оренбуржья
```

Перечислять пункты в коротком поле стоит, пока их мало: человек из Илека
ищет глазами своё название, а не слово «райцентры». Когда направлений
станет больше шести, список перестанет помещаться — тогда остаётся
короткий вариант.

## Описание

До 2000 символов. Этот текст — 1549 символов, запас есть.

```
Приложение для тех, кто регулярно ездит между Оренбургом и районными центрами области: Соль-Илецком, Акбулаком, Илеком и Александровкой.

Водитель публикует поездку и свободные места. Пассажир находит её в поиске и откликается. Дальше вы договариваетесь напрямую — по телефону, в сообщениях ВКонтакте или в Telegram.

Что умеет приложение:

• Поиск по направлению и дню. Восемь направлений: все поездки идут в Оренбург или из Оренбурга, прямых рейсов между райцентрами не бывает. Фильтры по цене, числу мест и роли — водитель или пассажир.
• Публикация поездки за минуту. Маршрут выбирается в два шага: сначала пункт, затем сторона. Дальше дата, время с шагом полчаса, число мест и цена.
• Отклики. Автор видит, кто откликнулся, и сам решает, кого взять. Свободные места пересчитываются автоматически.
• Отзывы и рейтинг. После поездки участники оценивают друг друга, и в следующий раз видно, с кем имеешь дело.
• Жалобы. На объявление, на отзыв и на профиль можно пожаловаться прямо из приложения. Жалобу разбирает человек: при подтверждённом нарушении содержимое удаляется, а нарушителю закрывается доступ.
• Работа при плохой связи. Последние поездки вместе с номерами сохраняются на устройстве: если сервер недоступен, список всё равно откроется и по нему можно позвонить.

Чего в приложении нет:

• Оплаты внутри. Деньги передаются напрямую водителю, приложение в расчётах не участвует.
• Посредников. Это доска объявлений, а не служба заказа такси: все договорённости — между вами.

Цена за место — от 500 до 850 ₽, её назначает автор поездки.
```

> Про комиссию в описании намеренно не сказано ничего. Сейчас её нет, но
> если появится монетизация для водителей, фраза «комиссию не берём» в
> опубликованной карточке начнёт работать против вас — и объясняться
> придётся и с пользователями, и с модерацией. Разбор моделей —
> в `docs/monetization.md`.

> Строка про оплату внутри — утверждение о сегодняшнем дне, а не
> обещание навсегда. Если платежи появятся, эту строку придётся
> переписать вместе с политикой конфиденциальности: сейчас она
> платёжных данных не называет.

## Что приложение собирает о пользователе

Это понадобится и для политики конфиденциальности, и для ответов
модерации. Список точный, он сверен с кодом — не добавляйте в него лишнего
и не убирайте нужного.

| Что | Откуда | Зачем |
|---|---|---|
| Идентификатор ВКонтакте | Подписанные launch-параметры запуска | Понять, кто публикует поездку и кто откликается |
| Идентификатор Telegram | Подписанные данные запуска (`initData`) | То же самое для тех, кто пришёл из Telegram |
| @username в Telegram, если он есть | Те же подписанные данные | Кнопка «Написать»: диалог открывается только по имени |
| Имя, фамилия, фото, город | Профиль той площадки, через которую человек вошёл | Показать автора поездки и участников откликов |
| Номер телефона | Пользователь вводит сам либо подставляет из профиля ВКонтакте | Чтобы попутчики могли позвонить. Обязателен тем, у кого нет страницы ВКонтакте: иначе с ними не связаться |
| Текст объявлений, откликов и отзывов | Вводит пользователь | Содержание самого сервиса |
| Жалоба: объект, причина, пояснение | Пользователь, который жалуется | Постмодерация содержимого |
| Отметка о закрытом доступе и её дата | Ставит оператор по подтверждённой жалобе | Не пускать нарушителя обратно |
| Дата согласия с политикой конфиденциальности | Фиксируется при первом входе | Подтверждение согласия на обработку |

Данные хранятся на собственном сервере владельца приложения. Третьим лицам
не передаются, в рекламные сети и аналитику не уходят — ни то, ни другое в
приложении не подключено.

Политика конфиденциальности: <https://vk-rideshare.duckdns.org/privacy>,
действующая редакция от 13.10.2026.

## Ответы на типичные вопросы модерации

**Как приложение зарабатывает?** Сейчас никак. Платежей внутри приложения
нет, оплата поездки происходит напрямую между пассажиром и водителем.
Способы монетизации рассматриваются, но ни один не запущен.

**Кто отвечает за поездку?** Участники договариваются между собой.
Приложение — доска объявлений, оно не организует перевозку и не выступает
стороной договора.

**Как модерируется пользовательское содержимое?** Постмодерация с жалобами
прямо в интерфейсе:

- кнопка «Пожаловаться» есть у объявления, у отзыва и у профиля;
- причина выбирается из закрытого списка: реклама или спам, оскорбления,
  обман, чужие персональные данные, другое (в последнем случае пояснение
  обязательно);
- жалобы разбирает человек — владелец приложения, через отдельный экран
  внутри приложения;
- по подтверждённой жалобе содержимое удаляется, а нарушителю закрывается
  доступ: он не может ни публиковать, ни откликаться;
- анонимных публикаций не бывает: каждый запрос несёт подписанные данные
  запуска площадки, автор известен всегда;
- адрес для обращений, в том числе для спора о закрытом доступе, указан в
  политике конфиденциальности, раздел 15.

**Есть ли возрастные ограничения?** Да. Политика конфиденциальности
(пункт 14.1) указывает, что сервис не предназначен для лиц младше 18 лет и
целенаправленный сбор данных несовершеннолетних не ведётся. Если в кабинете
есть поле возрастного ограничения, значение в нём должно совпадать с этим
пунктом — расхождение карточки и политики модерация находит быстро.

**Где политика конфиденциальности?** <https://vk-rideshare.duckdns.org/privacy>
— постоянный адрес, та же ссылка указана в приложении на экране согласия и
в профиле.
