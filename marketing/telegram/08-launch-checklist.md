## 5. Подстановка маркеров

Перед публикацией в текстах не должно остаться ни одного маркера. Их три вида:

- [ ] `[ССЫЛКА_МИНИ_АППА]` — во всех постах.
- [ ] `@po_puti56` в примерах JSON — заменить на настоящий @username канала.
- [ ] `[ЦИФРА]` — настоящие числа. Маленькое настоящее число работает лучше
      расплывчатого «немного»: его можно проверить.
- [ ] Данные поездок в шаблонах 1 и 2: `[ОТКУДА]`, `[КУДА]`, `[ДАТА]`,
      `[ВРЕМЯ]`, `[ЦЕНА]`, `[МЕСТ]`.

Проверка одной командой, из корня репозитория:

```bash
grep -rn '\[ССЫЛКА_МИНИ_АППА\]\|\[ЦИФРА\]\|po_puti56' marketing/telegram/
```

В самих файлах каталога маркеры остаются — это шаблоны. Команда нужна, чтобы
проверить **скопированный текст** перед отправкой: в нём совпадений быть не
должно.

## Как считались символы

Во всех файлах длина указана в кодовых единицах UTF-16 — так считает сам
Telegram, и в тех же единицах заданы смещения в `entities`. Для русского
текста это ровно число символов; эмодзи из верхних плоскостей занимает две
единицы вместо одной. Пересчитать любой текст можно так:

```bash
python3 -c "import sys;t=sys.stdin.read().rstrip(chr(10));print(sum(2 if ord(c)>0xFFFF else 1 for c in t))" < текст.txt
```

Длина, указанная в каждом файле, — это длина текста между линиями `---`,
посчитанная этой же формулой.
