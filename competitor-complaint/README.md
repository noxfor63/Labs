# Проверка мини-приложения «Попутчики» (vk.ru/app7156919_-196697873)

**Статус: работа остановлена на шаге 1.** Не хватает исходных материалов,
без которых аудит получится недоказуемым. Что именно нужно — ниже.

## Почему остановка, а не «пока напишу по памяти»

Задача требует точных номеров и цитат действующих правил VK. Из этой среды
сайты VK недоступны: исходящие запросы к `dev.vk.com`, `dev.vk.ru`,
`vk.com`, `vk.ru` и даже к веб-архиву отклоняются прокси (403 на CONNECT,
проверено 12.10.2026). Поиск находит только архивные редакции 2022–2023
годов, нумерация которых могла измениться.

Пересказывать правила по памяти нельзя: в жалобе неверный номер пункта
обесценивает весь документ, а проверять его будет модератор, у которого
действующий текст перед глазами.

## Чего не хватает

### 1. Первоисточники правил

Нужен текст, а не ссылка (ссылку я открыть не смогу). Для каждого
документа: полный текст, URL и дата, когда вы его открыли.

| Документ | Зачем |
| --- | --- |
| Правила размещения сервисов на платформе VK Mini Apps | основной документ для всех пунктов аудита |
| Требования к разработчику (сведения о владельце, контакты) | группа «юридические сведения» |
| Правила обработки данных пользователей платформой | группа «персональные данные» |
| Требования к возрастной маркировке | группа «возрастной рейтинг» |
| Правила приёма платежей в мини-приложениях | группа «платежи», если конкурент берёт деньги |

Как прислать: сохранить страницу целиком (Ctrl+S) или скопировать текст
(Ctrl+A → Ctrl+C) в файл и положить в `rules-raw/`. Либо вставить текст
прямо в чат. Если какой-то группы правил нет в природе — так и скажите, я
уберу группу из аудита, а не стану подбирать ей «похожий» пункт.

### 2. Доказательства

Папка `evidence/` сейчас пуста. Само приложение конкурента я открыть не
могу (тот же запрет прокси), поэтому проверить публично доступное
самостоятельно не получится — аудит целиком опирается на ваши материалы.

Что имеет смысл собрать, по группам проверки:

- **карточка в каталоге**: название, разработчик, возрастная маркировка,
  описание — одним скриншотом, с видимым адресом страницы;
- **юридические сведения**: экран приложения в месте, где должна быть
  ссылка на политику конфиденциальности и соглашение; если ссылка есть —
  скриншот открытой политики;
- **персональные данные**: экраны, где приложение просит данные (телефон,
  доступ к профилю), и экран согласия, если он есть;
- **платежи**: экран оплаты с видимым способом (если оплата есть);
- **контент и жалобы**: экран объявления/сообщения между пользователями и
  место, где должна быть кнопка жалобы;
- **работоспособность**: если что-то не работает — скриншот ошибки с
  видимым временем.

К каждому файлу — строка в `evidence/index.md`: имя файла, что на нём
видно, когда и где снято. Без этого скриншот в жалобе не доказательство:
модератор не знает, когда он сделан.
