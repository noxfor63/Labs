## Как заполнится этот файл

Для каждого правила, попавшего в аудит:

- точная цитата (дословно, без пересказа);
- номер пункта и название раздела;
- URL страницы;
- дата редакции, если она указана на странице;
- дата обращения.

Источник текста: материалы, присланные владельцем задачи (см. `README.md`,
раздел «Чего не хватает»), с указанием, кто и когда их получил.
